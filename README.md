# 坦克大战 · Tank Battle

一个用纯 HTML5 Canvas + JavaScript 实现的经典坦克大战小游戏，单文件即可运行，无需任何依赖。

## 🎮 玩法

- 控制你的坦克，**保卫基地 🏠**，消灭所有敌方坦克即可过关。
- 基地被摧毁或生命耗尽则游戏结束。
- 敌人生成数量与强度随关卡提升。

## 🕹 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | 方向键 / `WASD` |
| 开火 | 空格 / `J` |
| 暂停 | `P` |
| 静音 | `M` |
| 开始 / 确认 | `Enter` |

移动端（触屏设备）会显示虚拟摇杆与开火按钮。

## 🏆 道具

| 道具 | 效果 |
| --- | --- |
| ⭐ 火力 | 提升火力等级（射速更快，最高可击穿钢墙） |
| 🛡 护盾 | 短暂无敌 |
| ❤ 生命 | 增加一条生命 |
| 💣 清屏 | 立即消灭场上所有敌人 |

## 🚀 运行

直接用浏览器打开 `index.html` 即可，或者：

```bash
# 使用任意静态服务器
python -m http.server 8000
# 打开 http://localhost:8000
```

## 🛠 技术

- 纯原生 JavaScript（ES6），Canvas 2D 渲染
- 像素风放大渲染（`image-rendering: pixelated`）
- Web Audio API 合成音效
- 响应式布局，支持键盘与触屏
